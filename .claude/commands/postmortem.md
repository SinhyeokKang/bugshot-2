---

회귀·버그를 잡아 고치고 검증까지 마쳤을 때, "왜 틀렸나 → 다음에 어떻게 막나"를 `docs/POSTMORTEM.md`에 한 항목으로 남기는 스킬. 6축 평가에서 최저였던 **실패 사후분석(FAIL)** 축을 메우는 회로다 — 자동 복구(e2e 루프 등)는 그 자리만 메우지, 같은 함정 재발을 막지 못한다.

항목마다 **영역·계열·그물 태그**를 달아 `pnpm postmortem:report`가 반복 축을 집계한다. 기록만 쌓고 집계가 없으면 "어느 영역이 반복 함정인가"를 셀 수 없어 개별 회고에서 끝난다 — 태그가 그 루프를 닫는다.

**리포트가 아니라 기록 스킬**이다. 코드(`src/`)는 건드리지 않고 `docs/POSTMORTEM.md`만 추가한다. 빌드·커밋 안 함(커밋은 `/push`가 `docs(POSTMORTEM): ...`로).

## 사용

- `/postmortem` — 직전 컨텍스트(방금 고친 버그/회귀)에서 항목을 추론해 작성.
- `/postmortem <설명>` — 대상 명시. 예: `/postmortem logs.html 첨부 누락`.

## 절차

### 1. 사례 확정

직전 대화에서 **무엇이 고쳐졌는지** 확정한다 — 증상, 근본 원인, 손댄 파일. 불확실하면 추측하지 말고 해당 픽스의 diff·커밋을 다시 본다. 픽스가 아직 검증 안 됐으면(테스트 미통과 등) 회고는 이르다 — 먼저 닫으라고 안내하고 중단.

### 2. 비자명성 필터

`docs/POSTMORTEM.md`는 **코드만 읽어선 안 보이는 구조적 함정·재발 패턴**만 담는다. git diff만 봐도 자명한 일회성 오타·단순 누락은 기록하지 않는다(그건 git history가 이미 한다). 남길 가치가 없으면 그렇게 말하고 중단.

판단 기준 — 아래 중 하나면 기록할 가치가 있다:
- 같은 수정을 **여러 곳에 동시에** 해야 했다(복제된 로직·N개 빌더·N개 어댑터).
- 표면 증상과 근본 원인이 **다른 레이어**였다(예: "첨부 안 됨"인데 원인은 본문 빌더 게이트).
- 다음에 같은 류를 막는 **구체적 grep 패턴/전수 대상**이 있다.

### 3. 작성 (docs/POSTMORTEM.md 맨 위 항목으로 추가)

파일 상단 형식 안내를 따른다. `## YYYY-MM-DD — <한 줄 제목>` 헤딩 + 태그 3줄 + 본문 4줄:
- **영역**: 어디서 깨졌나 (1개 이상).
- **계열**: 왜 깨졌나 (0개 이상 — 해당 없으면 줄 생략).
- **그물**: 무엇이 잡았어야 했나 (정확히 1개).
- **증상**: 사용자가 관측한 잘못된 동작.
- **근본 원인**: 표면 말고 코드상 진짜 원인.
- **재발 방지**: grep 패턴·전수 대상·테스트 등 구체적 체크.
- **관련**: 손댄 파일·핵심 함수(`file:func` 형태).

기존 항목 위(`---` 구분선 아래 첫 항목)에 끼운다 — 최신이 위. 날짜는 오늘.

**태그 vocab은 `docs/POSTMORTEM.md`의 "태그" 표를 그대로 쓴다**(단일 출처는 `scripts/postmortem-report.mjs`의 `AREAS`·`PATTERNS`·`NETS`). 새 값을 지어내지 않는다 — 기존 값으로 억지가 아니면 기존 값을 쓴다. 축이 잘게 쪼개지면 반복 함정이 안 드러난다.

**그물 축 판정 기준** — "이 함정을 자동으로 잡으려면 무엇이 필요했나"이지 "이번에 무엇이 잡았나"가 아니다. 순수 함수로 재현되면 `unit`, 렌더·인터랙션이 필요하면 `jsdom`, 확장 실행이 필요하면 `e2e`, 레이아웃·색·포인터라 jsdom으로 원리상 불가하면 `시각`, 실제 탭·권한 조작이 필요하면 `수동`, 코드로 못 막으면 `없음`.

### 4. 검사 + 보고 + 종료

`pnpm postmortem:check`로 태그 형식을 확인한다(vocab 오타·태그 누락·헤딩 유실을 잡는다 — red면 고치고 재실행). 그 다음 `pnpm postmortem:report`를 돌려 **이번 항목이 기존 반복 축에 얹혔는지** 본다 — 같은 `영역 × 계열` 조합이 이미 3건 이상이면 그 사실을 보고에 포함한다(개별 회고가 아니라 구조 문제라는 신호).

추가한 항목 제목, 핵심 재발방지 한 줄, 반복 축 여부를 보고하고 종료. 빌드·커밋·푸시 안 함.

## 금지 사항

- **코드 수정 금지** — `docs/POSTMORTEM.md`만.
- **자명한 것 기록 금지** — 2단계 필터를 통과 못 하면 중단.
- **빌드·커밋·푸시 금지**.
- **검증 안 된 픽스 회고 금지** — 먼저 픽스를 닫는다.
