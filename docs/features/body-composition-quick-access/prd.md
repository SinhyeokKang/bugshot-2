# 본문 구성 빠른 접근 (Body composition quick access)

## 배경

이슈 본문의 섹션 구성(사용 여부·순서)은 **설정 > 이슈 > 본문 구성**에서만 바꿀 수 있다. 그런데 "이 섹션은 이번 이슈에 필요 없다"는 판단이 서는 시점은 설정 화면이 아니라 **작성 중이거나 프리뷰를 보는 순간**이다.

지금은 활성화된 섹션을 빈 값으로 두고 제출하면 본문에 `(없음)` 플레이스홀더가 남는다(`buildIssueMarkdown.ts:298,303` 및 8개 플랫폼 빌더 전부 동일). 이 표기는 "작성자가 의도적으로 비웠다"는 신호라서 유지할 가치가 있고, 조용히 드롭하면 표시면(프리뷰·상세·logs.html Report 탭)과 제출 본문이 어긋난다. 따라서 해결책은 출력 규칙 변경이 아니라 **설정 접근 경로를 작성 흐름 안으로 끌어오는 것**이다.

## 목표

- 이슈 작성 패널(drafting)과 프리뷰 패널(preview) 푸터에서 **한 번의 클릭으로 본문 구성 설정을 열 수 있다**.
- 다이얼로그에서 섹션 **사용 여부 토글**과 **순서 재정렬**을 모두 할 수 있다.
- 변경은 즉시 반영되어, 다이얼로그를 닫으면 뒤의 작성/프리뷰 패널이 갱신된 구성으로 보인다.
- 변경은 전역 영속되어 **설정 > 이슈 > 본문 구성**과 항상 같은 값을 가리킨다(양방향 단일 출처).
- 본문 구성 UI는 설정 탭과 다이얼로그가 **한 벌의 컴포넌트**를 공유한다.

## 비목표 (Non-goals)

- 빈 섹션의 `(없음)` 출력 규칙 변경. 현행 유지한다.
- 이슈별(per-issue) 섹션 구성. 이 설정은 전역이고, 과거 이슈의 상세·복사 본문에도 소급 적용된다(현행 동작 그대로).
- `DraftDetailDialog`(제출 완료 이슈 상세)에 같은 진입점 추가. 소급 변경을 "이 이슈만 고치는 것"으로 오해할 여지가 커서 제외한다.
- 섹션 라벨 편집(`labelOverride`), 섹션 추가/삭제. 현재 설정 탭에도 UI가 없다.
- 다이얼로그 취소(rollback). 스토어 액션이 즉시 persist라 취소 개념이 없고, 되돌리기는 **기본 순서 복원** 버튼이 담당한다.
- 전역 설정임을 알리는 캡션/고지 문구. 넣지 않는다.

## 사용자 시나리오

### 1. 작성 중 불필요한 섹션 끄기

1. 캡처를 마치고 이슈 작성 패널에 들어온다.
2. **비고** 섹션이 켜져 있지만 이번 이슈엔 쓸 내용이 없다.
3. 푸터의 `⚙`(Settings2) 버튼을 누른다 → **본문 구성** 다이얼로그가 열린다.
4. 비고 스위치를 끈다.
5. **확인**을 눌러 닫는다 → 작성 패널에서 비고 입력 영역이 사라진다.
6. 제출된 본문에 비고 섹션이 없다.

### 2. 프리뷰에서 `(없음)`을 보고 끄기

1. 프리뷰 패널에서 **기대 결과** 섹션이 `(없음)`으로 렌더된 걸 본다.
2. 푸터 `⚙` → 기대 결과 스위치 off → **확인**.
3. 프리뷰 본문이 즉시 갱신되어 해당 섹션이 사라진다.
4. 그대로 **이슈 제출**을 누른다.

### 3. 순서 재정렬

1. 작성 중 미디어를 맨 위로 올리고 싶다.
2. 푸터 `⚙` → 드래그 핸들(또는 키보드: 핸들 포커스 → Space → 방향키 → Space)로 **미디어 · 로그**를 최상단으로 이동.
3. **확인** → 작성 패널의 섹션 순서가 그대로 바뀐다. **입력해 둔 텍스트는 모두 유지된다.**

### 4. 껐다 다시 켜기 (데이터 보존)

1. 설명 섹션에 텍스트를 입력한 상태에서 설명을 끈다 → 입력 영역이 사라진다.
2. 다시 켠다 → 입력해 둔 텍스트가 그대로 돌아온다.
   (`draft.sections[id]`는 유지되고 `bodyBlocks`가 렌더만 건너뛴다.)

### 5. 설정 탭과의 동기

1. 다이얼로그에서 비고를 끈다.
2. 설정 > 이슈 > 본문 구성으로 이동한다 → 비고가 꺼져 있다.
3. 설정 탭에서 다시 켠 뒤 이슈 작성으로 돌아오면 비고 섹션이 있다.

### 엣지 케이스

- **미디어 행**: 스위치가 없다(순서만 조정). 본문 emit은 데이터 기반이라 on/off 대상이 아니다.
- **기본 순서일 때**: 다이얼로그 푸터의 **기본 순서 복원** 버튼이 `disabled`.
- **AI 초안 / 재현 과정 자동채움 로딩 중**: 푸터 `⚙` 버튼이 `disabled`. 로딩 중 섹션 구성이 바뀌면 `mergeAiSectionsPreservingBlocks`가 돌아올 때 대상 구성이 어긋난다.
- **제목이 비어 있을 때**: `⚙` 버튼은 눌린다(미리보기 버튼의 `titleMissing` 조건을 따라가지 않는다).
- **재현 과정을 작성 중에 켰을 때**: AI 자동채움은 발화하지 않는다. 자동채움은 작성 화면 **진입 시점**의 구성으로만 판단한다.

## 성공 기준

- drafting·preview 두 패널 푸터에서 다이얼로그를 열어 토글·재정렬할 수 있다.
- 다이얼로그에서 바꾼 값이 설정 탭에, 설정 탭에서 바꾼 값이 다이얼로그에 즉시 반영된다(`chrome.storage` 영속).
- 순서를 바꾸고 닫아도 각 섹션에 입력해 둔 텍스트와 포커스 가능 상태가 유지된다.
- 설정 탭과 다이얼로그의 섹션 행 UI가 같은 컴포넌트에서 렌더된다(중복 구현 없음).
- 새 i18n 키 없이 기존 키(`settings.bodyComposition`·`settings.reorder.reset`·`common.ok`)만으로 동작한다.
