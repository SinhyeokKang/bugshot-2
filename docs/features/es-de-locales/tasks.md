# 스페인어·독일어 로케일 추가

## 범위와 결정

- 기존 ko/en/fr 구조에 `es`(Español)·`de`(Deutsch)를 추가한다. 새 i18n 구조나 별도 PRD/설계 단계는 필요하지 않다.
- 확장 UI, 이슈 본문 언어, 내보낸 로그 뷰어, Chrome manifest 메시지, 브라우저 언어 감지, 날짜 표기, AI 출력 언어 auto 연결을 포함한다.
- 스페인어는 지역별 사전을 나누지 않는 공통 `es`이며 날짜 표기는 `es-ES`, 독일어는 `de-DE`를 사용한다. 기존 prefix 기반 지역 태그 해석을 유지한다.
- 사용자가 원어민 검수를 제외했다. 번역 초안 자체 검토와 자동 검증·레이아웃 검증은 수행한다.
- 사용자 확정 모델: 구현 `gpt-6-sol` / high, 독립 리뷰 `gpt-6-astra` / medium. 구현 1개 → 독립 리뷰 1개를 직렬로 운영한다. 추가 에이전트나 astra high로 확대하지 않는다.
- guide/ko·en 및 README의 지원 언어 안내는 맞추되 스페인어·독일어 가이드 전체 번역과 스토어 소개문 번역은 범위 밖이다.
- 기존 ko/en/fr 문구, 사용자 작성 본문, compact AI 정책, 저장 스키마, 개인정보 처리 동작을 변경하지 않는다.
- Codex 종착점은 로컬 dev 통합·커밋이다. 사용자 제공 AGENTS.md의 원격 작업 역할 분담에 따라 push/merge/deploy는 수행하지 않는다.
