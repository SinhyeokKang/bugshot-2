# es/de 번역 검수 반영

2026-10-06, [Opus 검수](./review-opus.md)의 P1·P2 및 P3 개선안을 반영했다. 원본 검수 보고서는 수정 전 상태를 기록한다.

- 구현: Codex Sol / high. 후속 검토: Codex Astra / medium.
- PAT·토큰 접두사·플랫폼 객체명·방향·접기 동작 오역과 로그 요약·액션 문법을 교정했다. 메인 사전과 로그 뷰어 공유 키도 함께 갱신했다.
- 스페인어 사용자 호칭은 tú, 독일어 본문은 Sie·동작 라벨은 부정사로 통일했다. 독일어 확장 설명은 130자로 유지했다.
- `Kontakt`/`Bewerten`와 요소 캡처 버튼 등 의도된 폭 축약은 유지했다. `editor.resetChanges.body`는 단복수 분기를 추가하지 않고 `los cambios ({count})`로 표현했다.
- 후속 검토의 잔여 3건도 교정했다: 독일어 날짜 단위를 `vor {n} Tg.`로, 웹훅 401 안내의 필드명을 `Secret`으로, 스페인어 API 키 라벨을 `Clave de API`로 맞췄다.
- ko/en/fr·키·보간 토큰·런타임 동작은 변경하지 않았다. 로그 뷰어 e2e의 스페인어 검색 placeholder 기대값을 갱신했다.

## 검증

- 전체 단위 테스트: 434개 파일, 8,560개 통과·기존 2개 스킵. 타입 검사 통과.
- 마지막 문구 교정 뒤 메인·로그 뷰어 사전 검사: 21개 통과.
- Codex 미러·diff 공백 검사 통과.
- 로컬 e2e·400px 시각 검증·배포 빌드는 실행하지 않았다. e2e는 `/push` 규칙대로 CI에서 검증한다. 이전 작업에서 남은 ko/en 가이드 언어 선택 스크린샷 갱신은 이번 번역 수정 범위에 포함하지 않았다.
