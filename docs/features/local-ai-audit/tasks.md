# 전체 감사 후속 수정

감사일: 2026-10-22. 사용자 승인: `orchestrate 하자. 모두 수정`.

## 수용 기준

- [ ] A / 감사 1: 여러 패널에서 설정을 변경해도 해제한 LLM·키가 되살아나지 않는다. 다른 필드 변경도 보존한다. 저장 실패·동시 쓰기·늦은 hydrate를 검증한다.
- [ ] B / 감사 2: 초안 확정 시 영상·각 로그의 목적 키 저장 실패는 기존 pending 원본을 보존한다. 성공 경로만 원본을 정리한다.
- [ ] C / 감사 3: AI 생성 중 키보드로 배경 제목·본문을 변경할 수 없다. 중단 버튼은 접근 가능하고 종료 후 포커스가 복원된다.
- [ ] D / 감사 4: Chrome AI 지원 언어 선언과 초안·재현 프롬프트가 일치한다. 한국어 정책은 사용자 결정 후 확정한다.
- [ ] D / 감사 5: downloadable/downloading/available/unavailable 상태를 구분한다. 사용자의 명시적 클릭으로 다운로드를 시작하고 진행·실패·완료를 표시한다. 자동 재현 생성이 다운로드를 시작하지 않는다.
- [ ] D / 감사 6: 명시적 중단 신호가 Chrome native prompt까지 전달돼 추론을 중단하고 세션을 정리한다. 취소 결과가 초안에 적용되지 않는다.
